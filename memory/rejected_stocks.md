# Rejected Stocks

Every idea that was investigated and **not** recommended, with the reason. This file exists so
the system does not re-research the same name every month and forget why it passed — and so that
if a rejected stock later doubles, the reasoning is on record to learn from.

**Append only.** If a rejection is later reversed, add a *new* entry reversing it; do not delete
the original.

Format:

```
### TICKER — Company Name — YYYY-MM-DD
- **Score at rejection:** N/100
- **Price at rejection:** $X.XX (source, date)
- **Primary reason rejected:** one sentence.
- **Supporting evidence:** the specific numbers/filings that decided it.
- **What would change my mind:** the concrete, observable event that would justify a re-look.
- **Re-review date:** YYYY-MM-DD
```
