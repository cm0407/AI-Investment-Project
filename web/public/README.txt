Files in public/data/ are generated.

They are written by:

    python scripts/export_site_data.py

Do not edit them by hand. A number typed in here has no source and no
timestamp, which makes it unverifiable - the same rule that applies to
everything under data/ in this project.

.nojekyll tells GitHub Pages to serve folders beginning with an underscore
(Next.js puts its JavaScript in _next/). Without it the site loads with no
styles and no interactivity.
